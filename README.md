# language-operator

Execution core for Language Object Level autonomous platform.

## Scope

language-operator provides the autonomous execution kernel with:

- task intake and orchestration
- policy decision engine
- execution and audit records
- event publication contracts
- health and readiness endpoints

## Technology Baseline

- Node.js 22
- TypeScript (strict)
- Fastify API surface
- Postgres + Redis + NATS integration contracts

## Development Status

This repository is under active development with branch-first workflow and gated CI.
