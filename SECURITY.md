# Security Policy

## Supported Versions

Only the latest `main` release branch is supported for security fixes.

## Reporting a Vulnerability

1. Do not open public issues for exploitable vulnerabilities.
2. Send a report to the security contact listed in organization profile.
3. Include reproduction steps, impact, and affected commit range if known.
4. We will acknowledge reports within 72 hours and provide remediation status updates.

## Security Requirements

- Signed commits and signed release tags are required on protected branches.
- All pull requests must pass static analysis, dependency checks, and secret scans.
- Critical findings block merges until remediated.
